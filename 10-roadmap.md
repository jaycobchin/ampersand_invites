# Product Roadmap

## Phase 0 — Foundation

Goal: establish product architecture and design language.

Deliverables:

- Authentication
- Role model
- Wedding domain model
- Vendor domain model
- Core design system
- Email infrastructure
- File storage
- Admin seed tools

---

## Phase 1 — Couple and guest MVP

Goal: a couple can manage a real guest list and collect RSVPs.

Deliverables:

- Wedding onboarding
- Dashboard
- Events
- Guest list
- CSV import
- Households
- +1s
- Wedding website
- RSVP
- Dietary requirements
- Checklist
- Basic budget

Milestone:

> A couple can run guest invitations and RSVP entirely through Ampersand.

---

## Phase 2 — Vendor marketplace MVP

Goal: create a usable marketplace loop.

Deliverables:

- Vendor registration
- Vendor profiles
- Five launch categories
- Portfolio
- Packages
- Marketplace browse
- Shortlist
- Structured enquiries
- Vendor lead inbox
- Quotes
- Couple selection
- Budget integration

Milestone:

> A couple can discover and select a vendor without leaving Ampersand for the core decision workflow.

---

## Phase 3 — Wedding operations

Goal: increase utility as the wedding approaches.

Candidate features:

- Seating planner
- Guest reminder campaigns
- Vendor-specific information sharing
- Payment milestones
- File attachments
- Vendor availability
- Planner collaborator roles
- Travel / hotel information

---

## Phase 4 — Transactions and communication

Goal: increase platform lock-in and monetization options.

Candidate features:

- Contracts
- E-signatures
- Deposits
- Vendor payments
- Automated reminders
- Messaging
- WhatsApp / SMS integrations
- Commission or subscription models

---

## Phase 5 — Intelligence

Goal: use connected wedding data to reduce planning work.

Candidate features:

- Personalized planning schedule
- Vendor recommendations
- Budget allocation suggestions
- Quote comparison summaries
- Dietary summary generation
- Seating suggestions
- Wedding-day run sheet generation

## Prioritization test

Before adding a feature, ask:

1. Does it improve the couple's ability to plan?
2. Does it reduce duplicated wedding information?
3. Does it improve guest coordination?
4. Does it improve vendor selection or fulfilment?
5. Does it create repeat platform usage?

If the answer is no to most of these, defer it.
