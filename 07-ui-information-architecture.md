# Guest experience

The guest experience should not resemble a dashboard.

## Pages

1. Wedding landing page
2. Event information
3. RSVP form
4. RSVP confirmation

Mobile-first principles:

- Large tap targets
- Minimal login friction
- No unnecessary navigation
- Preserve partially completed RSVP where possible
- Make event-specific attendance obvious
